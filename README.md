# InAmigos Foundation awareness webpage

A responsive, single-page awareness website built with plain HTML and CSS. The page introduces InAmigos Foundation, presents six initiatives, explains their shared purpose, and gives visitors ways to ask about volunteering or support.

## Preview the page

1. Extract the ZIP file.
2. Open `index.html` in a current web browser.

The page works without a build step. It uses original local SVG artwork. An internet connection is only needed to load the optional Google Fonts; system fonts are used if they are unavailable.

## Update the content

- Edit the text and links in `index.html`.
- Adjust colors, layout and responsive styles in `styles.css`.
- Replace the illustrations in `assets/` if official InAmigos photos or brand artwork become available.
- The contact buttons currently open an email to `support@inamigosfoundation.org.in`. Confirm the preferred volunteer and donation links with the foundation before publishing.

## Research and content notes

Information was checked on 22 November 2026. The foundation description, 2020 founding year, Bilaspur location, and community-development focus are based on the official InAmigos Foundation LinkedIn page. The six initiative names and concise descriptions are based on the official website's project summaries and the organization's public description. No impact totals or beneficiary numbers are included because I could not independently confirm current figures.

- [Official website](https://inamigosfoundation.org.in/)
- [Official InAmigos Foundation LinkedIn page](https://www.linkedin.com/company/inamigos-foundation/)

When checked, the official website's indexed homepage also surfaced unrelated spam-like outbound links. This page therefore uses the published contact email and LinkedIn profile for calls to action instead of linking to an online donation flow. Recheck the official site before publishing a live donation link.

The leaf mark and community garden illustrations are original artwork created for this awareness-page concept; they are not official InAmigos brand assets or photographs of actual project work.
